# GHL section exports

Generated by `npm run build`. Do not edit these files directly: edit the matching file in `pages/` or
`shared/`, rebuild, then paste the new snippet into GHL.

- One folder per page, one `.html` file per section, in page order (`01-…`, `02-…`).
- `shared/header.html` and `shared/footer.html` go on every page.
- Each page folder has a `PAGE-SETTINGS.md` with the page path, SEO title and description, indexing,
  install order and the background color for each GHL section and row.

Step-by-step instructions: `docs/installation-guide.md`.
